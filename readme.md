# Playwright typescript Examples

This project contains practical examples to learn and use [Playwright](https://playwright.dev/), a tool for automated testing of web applications.

## Contents

- Basic Playwright examples.
- Automated UI tests.
- Setting up and using Playwright with different browsers.
- Running tests in parallel.

## Requirements

- Node.js (version 14 or higher).
- npm or yarn installed.

## Installation

1. Clone this repository:
    ```bash
    git clone https://github.com/jvazquez1980/Playwright-Typescript.git
    ```
2. Install dependencies:
    ```bash
    npm install
    ```

## Usage

1. Run a basic example:
    ```bash
    npx playwright test
    ```
2. Open the test report:
    ```bash
    npx playwright show-report
    ```
